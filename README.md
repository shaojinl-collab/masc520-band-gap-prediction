Band Gap Prediction Using Neural Networks

MASC 520 Team Project

Team Members

Shaojinlin Yang

Yunshuo Tian

Project Overview

We will predict semiconductor band gaps using chemical composition and crystal structure. The project will examine whether adding structural descriptors improves predictions compared with using composition alone.

Data

We plan to obtain crystal structures and calculated band gaps from the Materials Project, focusing on ordered inorganic compounds with band gaps between 0.1 and 3.0 eV.

Methods

We will compare three feature sets:

Chemical composition

Composition and overall crystal structure

Composition, overall structure, and local atomic distances

A small neural network and a random forest will be evaluated using mean absolute error.

Tools

Python, Pymatgen, NumPy, Pandas, PyTorch, and Scikit-learn.

Project Status

Proposal stage. Code, data preparation instructions, and results will be added as the project progresses.
